## 📌 Descripción del Proyecto

Kash-Bol es una plataforma pensada para digitalizar el proceso de registro de clientes (KYC), solicitud de créditos y validación de documentos según la normativa de la Autoridad de Supervisión del Sistema Financiero (ASFI) de Bolivia. Este repositorio contiene la planificación ágil y el desarrollo incremental del MVP a lo largo de 3 semanas de práctica.
